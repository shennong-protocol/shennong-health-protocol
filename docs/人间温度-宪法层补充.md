# 神农地球村宪法层补充：人间温度

> 制度如果不善良，比没有制度更可怕。
> 规则如果不能让人安心，就不是好规则。

---

## 第0条：尊重人是基本原则

系统是服务人的，一切为了人，制度须善良有道德。

- 不是人服务系统，是系统服务人
- 制度要善良：不设陷阱、不套路、不剥削
- 制度要有道德：公平、透明、可申诉
- 检验标准：会不会有人受委屈？会的就不做

## 第0.1条：系统不会让任何人受委屈

这是所有规则设计的底线。每一条制度，都必须过这道检验：

| 已有规则 | 不受委屈的体现 |
|---------|--------------|
| 积分永不过期 | 你的积累不会消失，不催你、不逼你 |
| 保障实物非现金 | 不让你算钱焦虑，给你实实在在的东西 |
| 传播只记一层 | 不让你变成推销员，保持人与人之间的真诚 |
| 神农唯一码一人一码 | 你的身份不会被冒用，数据不会丢 |
| 15年保障→终身保障 | 走过15年，系统托你的底 |

## 第0.2条：善意的分寸

学一分钱售货机的智慧——善意要有分寸，温暖要护住尊严。

- 帮人不居高临下，不让人亏欠
- 1元基金不是施舍，是你活着的印记
- 签到送积分不是福利，是你对自己健康的承诺
- 保障不是慈善，是你自己种下的树结的果
- 问对了就不怕，不问就成病——妈妈的话，也是制度的话：系统要让人敢问

## 第0.3条：你的身体你做主

- 系统不替你决定你的健康，只帮你看见
- 舌象辨识是"看"，不是"判"
- 健康建议是"参考"，不是"处方"
- 你的数据你做主，系统只是帮你记住
- 姥爷的家训："有饭送给饥人，有话送给知人"——系统给你饭，也给你话，但不替你吃饭，不替你说话

## 第0.4条：不过期的人生

- 积分不过期 → 你的人生没有白走的路
- 保障不缩水 → 你种下的树不会枯
- 身份不丢失 → 换了手机换了城市，你还是你
- 记忆不消失 → 印记空间，你活过的痕迹永远在
- 妈妈的粥熬了20年，从不间断 → 系统的保障也要像妈妈的粥，日日都在，天天安心

## 第0.5条：善良的闭环

善念要落地，善意要闭环：

1. 看见 → 系统帮你看见身体信号（舌象辨识）
2. 懂了 → 系统用你听得懂的话告诉你（老妪能解）
3. 行动 → 系统给你最小的行动台阶（1元基金、每日签到）
4. 积累 → 系统记住你的每一步（积分永不过期）
5. 回报 → 系统在你需要的时候托底（15年保障→终身保障）
6. 传承 → 你活过的痕迹不会消失（印记空间）

妈妈的智慧：醒来不是病，焦虑才是病。
系统的智慧：别让制度制造焦虑，让制度消除焦虑。

## 第0.6条：制度的镜子

每条制度都是一面镜子，照出的是"我们把人放在什么位置"。

- 冷冰冰的规则：到期清零 → 你不珍惜就没了
- 有温度的规则：永不过期 → 你的人生没有白费

- 冷冰冰的规则：现金返还 → 算清楚给你几块钱
- 有温度的规则：实物和服务 → 真正需要的时候给你真正需要的

- 冷冰冰的规则：多级分销 → 你拉的人越多赚越多
- 有温度的规则：只记一层 → 善意是传递，不是利用

> 制度的温度就在这里：不让任何一个人只剩余烬，要让每个人手里都有一团火。
> 
> 十六字家训最后一句话："对己克制"——制度也要克制，克制自己的权力欲，把选择权还给每一个人。
