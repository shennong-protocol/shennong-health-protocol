## 三、基金架构设计

### 3.1 总基金：生命延续

**定义**：神农地球村的公共保障池，承载集体记忆和互助精神。

**资金来源**：
1. 用户创建子基金时的1元基础注入
2. 无继承人用户的保障额度注入
3. 商家交易利润的公共分成
4. 爱心人士的自愿捐赠
5. 积分兑换剩余回流

**用途**：
1. 无继承人死亡后的集体保障
2. 1元基金基础保障
3. 平台公共支出
4. 紧急情况救济
5. 集体精神文明建设

### 3.2 子基金分类

| 类型 | 创建门槛 | 创建者 | 命名权 | 主要用途 | 继承类型 |
|------|---------|--------|--------|---------|---------|
| 个人子基金 | **1元** | 用户 | 用户自命名 | 个人价值延续 | 物质/事业/精神 |
| 品牌子基金 | 100元 | 商家/品牌 | 品牌方命名 | 品牌形象传承 | 品牌延续 |
| 慈善子基金 | 0元 | 平台/公益 | 系统命名 | 爱心传递 | 开放捐赠 |

### 3.3 子基金命名规则

**个人子基金命名（"活着的印记"命名）**：
- 用户享有子基金命名权，体现个人意志
- 命名长度：2-20个字符
- 合规审核（自动+人工）：
  - ❌ 禁用词过滤：政治、宗教、色情、违禁品等
  - ❌ 品牌侵权：不能使用知名商标、品牌名
  - ❌ 绝对化用语："最"、"第一"、"绝对"等
  - ✅ 审核通过后生成唯一基金代码

**品牌子基金命名**：
- 需提供品牌授权证明
- 命名需与商标注册一致
- 商业合规审核

## 四、资金来源机制

### 4.1 1元基金基础注入

**创建个人子基金时**：
- 最低金额：1元（或等值积分）
- 这1元进入总基金池"生命延续"
- 用户获得子基金命名权和印记空间

**意义**：
- 极低门槛让每个人都能拥有自己的印记
- 1元汇聚成公共保障池
- 物质贡献 + 精神印记双重价值

### 4.2 消费注入比例

**个人消费利润沉淀**：

| 阶段 | 消费盈利中注入比例 | 注入去向 |
|------|-------------------|---------|
| 前5年 | 50% | 保障池（总基金） |
| 5-10年 | 40% | 保障池 + 个人子基金 |
| 10年后 | 30% | 保障池 + 个人子基金 |

**注入公式**：
```
个人子基金注入 = 消费金额 × 利润率 × 注入比例
```

### 4.3 商家交易利润注入

商家在神农平台的每笔交易，按约定比例注入基金：

| 商家类型 | 注入比例 | 注入去向 |
|---------|---------|---------|
| 普通商家 | 1%-5%（自选） | 品牌子基金 + 总基金 |
| 优选商家 | 3%-10%（自选） | 品牌子基金 + 总基金 |
| 创始商家 | 5%-15%（自选） | 品牌子基金 + 总基金 |

### 4.4 传播收益注入

**只记一层，不裂变**（合规红线）

| 传播类型 | 奖励机制 | 注入机制 |
|---------|---------|---------|
| 直接传播 | 邀请新用户注册成功，奖励邀请人10积分 | 被邀请人消费时，0.1%注入总基金 |
| 内容传播 | 有效阅读量达标后，奖励创作者积分 | 平台广告收益的1%注入总基金 |

### 4.5 积分兑换剩余回流

当用户使用积分兑换服务/产品时：
- 兑换价格的80%用于支付服务/产品成本
- 剩余20%注入总基金公共池

**合规说明**：积分不可提现为现金，回流机制仅用于平台内循环。

### 4.6 自愿捐赠

有余力者可以自愿向以下对象捐赠：
1. 总基金公共池
2. 指定个人子基金
3. 慈善子基金

**激励措施**：
- 捐赠公示（匿名可选）
- 贡献排行榜
- 匹配捐赠：平台1:1配捐（上限100元/月）

## 五、双层继承机制

### 5.1 物质继承

**适用场景**：有法定继承人或指定继承人的情况

**继承规则**：
1. 法定继承人自动继承100%子基金余额
2. 用户可生前指定继承人，最多3人
3. 可设置继承比例分配（如：配偶60%，子女40%）
4. 继承人需为神农平台注册用户

**继承流程**：
```
用户死亡认证 → 触发继承机制 → 通知继承人 → 继承人确认 → 资产转移
```

**物质继承的延续**：
- 继承人继承后，可选择：
  - A. 提取现金价值（限实物/服务折算）
  - B. 注入自己名下子基金
  - C. 捐赠至慈善子基金

### 5.2 事业继承

**适用场景**：用户生前创建的事业、项目、技能结晶

**继承内容**：
| 类型 | 举例 | 继承方式 |
|------|------|---------|
| 技能成果 | 健康食谱、养生方案 | 可继续使用、改进 |
| 项目成果 | 发起的研究课题 | 有人接手继续 |
| 人脉资源 | 社区关系、合作网络 | 有人传承维护 |
| 数字资产 | 内容创作、数据积累 | 版权继承、内容复用 |

**事业继承规则**：
1. 用户可生前指定事业继承人
2. 事业继承人不限于亲属
3. 事业子基金用于支持事业延续
4. 继承人需承诺延续或公开遗产

### 5.3 精神继承

**适用场景**："死有人想"的制度载体

**精神遗产类型**：
| 类型 | 举例 | 传承方式 |
|------|------|---------|
| 思想智慧 | 人生感悟、哲学思考 | 文章收录、语音/视频保存 |
| 教育内容 | 课程、讲座、经验分享 | 授权传播、持续更新 |
| 榜样力量 | 善行记录、公益参与 | 故事传播、精神激励 |
| 社区贡献 | 互助记录、帮助他人 | 功德碑、精神传承 |

**精神继承规则**：
1. 用户可生前创建精神子基金
2. 内容审核通过后公开
3. 后人可点赞、评论、传播
4. 优质精神遗产可获"精神传承奖"

### 5.4 无继承人优先保障

**触发条件**：用户死亡且无指定/法定继承人

**处理流程**：
```
无继承人判定 → 子基金余额转入总基金 → 优先用于集体保障
```

**总基金使用优先级**：
1. 基础食物供给
2. 居住保障
3. 质量提升
4. 精神文明建设
5. 平台运维

**设计理念**：让每一份价值都服务于生态，让每一个生命都被记得。

## 七、合规红线（必须遵守）

### 7.1 绝对禁止

| 红线ID | 内容 | 违规后果 |
|--------|------|---------|
| F-R-001 | 积分不可提现为现金 | 永久封禁 |
| F-R-002 | 不设三级分销 | 封号+资金冻结 |
| F-R-003 | 不承诺投资回报率 | 下架+追责 |
| F-R-004 | 不夸大健康功效 | 内容下架+扣分 |
| F-R-005 | 不无资质行医 | 法律追责 |
| F-R-006 | 传播收益只记一层不裂变 | 取消奖励+封号 |

### 7.2 关键合规说明

**积分定性**：
- 积分是平台虚拟服务凭证
- 不具备货币属性
- 不具备财产属性
- 仅限本人使用，不可转让

**基金定性**：
- 子基金是消费/贡献的记录载体
- 保障内容为实物和服务，非现金
- 继承为权益传承，非财产转移

**双轨隔离**：
- 积分管心（贡献记录、价值衡量）
- 股权管钱（资金流动、资产归属）
- 两套体系独立运行

### 8.3 印记空间存储体系

印记空间不只是文本字段，是**个人数字遗产仓库**——用户可上传回忆录、照片、文档、音视频等一切想传承的东西。

**存储内容类型**：
| 类型 | 格式 | 说明 |
|------|------|------|
| 文档 | PDF/DOCX/TXT | 回忆录、文章、日记 |
| 图片 | JPG/PNG | 照片、手写信扫描件 |
| 音频 | MP3/WAV | 语音留言、口述回忆 |
| 视频 | MP4 | 生活片段、口述历史 |

**空间与扩容**：
| 等级 | 容量 | 费用 | 说明 |
|------|------|------|------|
| 基础版 | 100MB | 免费（随1元基金附带） | 可存放文档+少量图片 |
| 铜印 | 1GB | 10元/年 | 回忆录+照片+少量音视频 |
| 银印 | 5GB | 30元/年 | 完整数字遗产空间 |
| 金印 | 20GB | 80元/年 | 大容量，含高清视频 |
| 永续印 | 不限 | 200元/一次性 | 永久存储，永不删档 |

**扩容规则**：
- 基础空间随1元基金免费附带，无需额外付费
- 扩容费用注入总基金池"生命延续"，不是平台利润
- 已购空间到期后，内容不删除，但暂停上传（续费恢复）
- "永续印"为一次性付费，内容永久保留——真正实现"灵能永流传"

**典型场景**：
> 二舅上传《车辙旁的马兰》回忆录PDF + 手稿照片 + 口述音频 → 银印空间

> 创业者上传项目文档+团队合影+创业日记 → 金印空间

## 十、运作流程

### 10.1 子基金创建流程（1元即可）

```

       ↓

```
